Shell *scripts* are programs that help automate tasks by storing a series of commands that are commonly executed together.

Instead of typing each command manually in the [[terminal]], you can keep them in a script file and run them whenever needed.

This saves time when performing repetitive tasks such as making backups, manage configurations, perform user audits, and so on.
