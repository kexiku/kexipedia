The `cut` command in [[Linux]] is used to cut a specific part of a file and print it to the [[Standard streams|standard output]] without changing the actual file.

## ✂️ Usage

### `-d`

- Set the field delimiter (default is tab)

### `-f <field>`

- Specifies which fields to extract (e.g., `-f 2` for the second field)

### `-c`

- Cuts specific characters or character ranges
