*dpkg* is a low-level package management tool used to install, build, remove and manage software [[packages]] on [[Debian derivatives|Debian-based]] Linux systems.

It serves as the core engine for higher-level, user-friendly tools like [[apt]] and [[aptitude]], which handle online repositories and automatic dependency fetching.
