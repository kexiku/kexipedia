The Windows Recovery Environment (WinRE) is a built-in diagnostic and repair tool in [[Windows]].

It helps troubleshoot and fix common system issues that can prevent Windows from starting.

## 🧰 Usage

- → *Settings*
	- → *Recovery*
	- → *Advanced Startup*
- Reboot
- → *Troubleshoot*
	- → *Advanced Options*
	- → *Command Prompt*
