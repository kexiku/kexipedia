Whenever a [[Linux]] user logs in to the system or opens a console window, the kernel runs a new *shell* instance.

The shell is responsibe for interpreting and executing commands entered in the [[terminal]], providing the output if needed.
It acts as an intermediary between the [[Users|user]] and the [[kernel]], ensuring that instructions are processed correctly.

In additional to executing individual commands, the shell can read sequences of commands stored in a file. These files are called *shell scripts*.

The shell gives users access to many powerful programs. They are called *CLIs*, or *Command Line Interfaces*.
