[Freedesktop.org](https://www.freedesktop.org/), formerly known as *X Desktop Group* (*XDG*), is an open-source project that creates and mantains software for desktop environments on [[Linux]] and UNIX-like operating systems.

It provides hosting for a number of relevant open-source projects like [[Wayland]], [[X11|X.Org]], [[D-Bus]], [[NetworkManager]] and [many others](https://www.freedesktop.org/wiki/Software/).

Freedesktop.org infrastructure encourages major software developer groups to cooperate rather than competing on low-level foundational components.

## 📋 XDG Standards

The project also defines a range of software specifications, often called *XDG standards*.

The most widely used XDG standard is the [[XDG Base Directory]] specification, which describes common environment variables such as `XDG_CONFIG_HOME` and their default values.
