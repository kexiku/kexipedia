*GUI*, *CLI*, and *TUI* represent the three primary styles of user interfaces used to interact with software systems.
They vary based on how information is displayed and how users input actions.

## 🖥️ GUI
### (Graphical User Interface)

- Provides rich graphics and layouts
- Uses non-linear, spatial navigation
- Demand high resources
- Interaction: mouse, touchpad, or touchscreen

## 📟 TUI
### (Terminal User Interface)

- Draws layouts inside a terminal
- Uses ASCII or Unicode for rendering
- Low resource usage
- Interaction: keyboard, mouse
## 🐚 CLI
### (Command Line Interface)

- Text-based interface
- Minimal recource usage
- Interaction: [[standard streams]]
