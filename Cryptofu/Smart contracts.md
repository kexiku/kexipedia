*Smart contracts* are software programs stored on [[blockchain]] that automatically execute specified actions when predefined conditions are met.

Smart contracts rely on rules defined by their *code*.
That code cannot be changed once created, which makes the transaction's outcome highly predictable: with the same circumstances, the smart contract will always produce the same result.

The main benefit of a smart contracts is the automatic execution: there is no need to wait for a third party side to interpret or negotiate the result.
This removes the need for trusted intermediaries.

Since all smart contracts are written in blockchain, their terms are visible to anyone on blockchain network.

> [!warning]
> The transaction code is designed to be interpreted by applications and wallets, not humans.
> 
> That led to the spread of a fraud scheme known as "blind signing", which tricks users to approve signed transactions without actually understanding what they do.
