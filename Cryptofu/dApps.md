*Decentralized applications*, or *dApps* are software programs that run on a [[blockchain]] network and provide services without relying on a central authority.

They are usually built on [[Ethereum]] blockhain since it makes [[smart contracts]] trasparent and convenient to use, allowing users to easily sign transactions via crypto [[wallets]] or web interfaces.

Decentralized applications serve various purposes like finance, gaming, and social media while safeguarding privacy and resisting censorship.

## Advantages of dApps

- 👤 **Accessibility**
	- No signup or email required

- ⚙️ **Efficiency**
	- DApps use smart contracts to handle user transactions automatically

- 🔒 **Security**
	- Blockchains make all the sensitive data immutable

- ☑️ **Transparency**
	- Each transaction is publicly verifiable

## 🕹️ Examples of dApps

- [[DEX|DEXes]]
- [[Wallets]]
- [[NFT]] marketplaces
- Lending apps
- Social media platforms
